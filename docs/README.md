## 0.5 目录结构（`docs/` 按读者意图分 4 类）

| 目录 | 读者意图 | 收录 |
|------|---------|------|
| [`01-规格/`](./01-规格/) | **我要改代码** | 实现规格 + 工程约定（布局 / 目录 / 工具链） |
| [`02-证据/`](./02-证据/) | **我要审计数据** | 测试 / 覆盖率 / 性能与体积证据 |
| [`03-过程/`](./03-过程/) | **我要复盘决策** | 立项期历史基线 + 仓库初始化与发布过程 + **工具链版本适配记录** |
| [`04-元/`](./04-元/) | **我要改文档 / README** | 文档体系规范、README 优化记录 |

- **`docs/README.md`（本文件）= 目录首页**：`docs/**` 除本文件外**不得**出现其他 `README.md`。
- **为什么只归 4 类**：类目越多，新增文档越难归类（Simplicity Gate）。
- **归类的兜底**：路径迁移由门禁共同兜底——文件级死链（`docs-link-check`）、
  章节引用（`docs-ref-check`）、清单自生成（`docs-index`）。详见 [AGENTS.md §四](../AGENTS.md)。

## 3. 发布与元数据

- **元数据**：`moon.mod`（`name` / `version` / `license` / `readme` / `description` / `repository`）。
- **发布前门禁**：`bash scripts/gates.sh`（全量）；发布凭据属本地私有，不进仓库、不进配置。
- **版本号单一事实源**：`moon.mod` 的 `version`；README **不得**写死当前版本号。

## 4. 文档维护

- **状态头三字段**（缺一不予合入）：`状态` | `日期：YYYY-MM-DD` | `索引：§N`。
- **单篇 ≤800 行**：`bash scripts/test-scale.sh` 与 §5 清单共同兜底。
- **死链零容忍**：`bash scripts/docs-link-check.sh` 检查受版本控制 Markdown 的相对链接。
- **章节引用门禁**：`bash scripts/docs-ref-check.sh` —— `S<N>x §M`（代号式）与
  `[标签](X.md) §M`（路径式）须在被引篇目存在该节（反引号内为「引述」不算活引用）。
- **索引清单为生成物**：§5 由 `bash scripts/docs-index.sh --write` 生成，
  `--verify` 校验；**禁止手改行数/篇数**。
- **日期漂移仅提示**：`bash scripts/docs-date-check.sh` 永不阻断。
