## 1. 议题定义

ISSUE #1「init repo」要求：

1. clone 参考仓库 `https://cnb.cool/tryandrun/moonbit_dev/fast_qr_moonbit`
2. 参考其配置 `.cnb.yml` / `.codebuddy/` / `scripts/` / `docs/` / `.vscode/`
3. 检查上述配置后生成 PR

**明确不做**：

- 不移植 `fast_qr_moonbit` 的业务代码（QR 实现）——本仓库是独立的 base64 项目。
- 不照搬其基准/审计类脚本（`bench-*`、`snapshot_gen_*`、`gc-compare.mjs` 等）——
  那些绑定 QR 的参考实现与比对口径，本仓库尚无对应对象。
- 不启用 push 流水线（理由见 §3）。

### 2.3 关键配置说明

- **未启用 push 流水线**：参考仓库也已于迭代中移除（每次推送重复全量构建+测试，收益不成比例）。
  门禁**不因不启用而失效**——全部阶段命令抽离在 `scripts/` 下，一条 `bash scripts/gates.sh` 跑全量；
  日后若需启用 CI，把该命令作为单个 stage 挂到 `push:` 即可，脚本零改动。
- **CPU 2 / 不启用 docker**：`.cnb.yml` 的 `runner.cpus: 2`，未声明 `docker` 环境与 DinD `services`。
- **工具链不钉版**：官方 CLI 只提供 `latest` / `nightly` 通道，按具体版本号下载会 404。
  `setup-moonbit.sh` 改为「装 `latest` + 装后断言实际版本 == 期望版本」，把静默漂移显式化。
